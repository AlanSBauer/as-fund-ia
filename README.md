# Análise de Sentimento com PLN

Atividade avaliativa da disciplina de Fundamentos de Inteligência Artificial, com o objetivo de classificar avaliações de clientes em positivas ou negativas.

## Requisitos

- Python 3.10 ou superior

## Instalação das dependências

`pip install -r requirements.txt`

## Execução

`python main.py`

Após a execução, os arquivos gerados estarão disponíveis na pasta `resultados/`.
